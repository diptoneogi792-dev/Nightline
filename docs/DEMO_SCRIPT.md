# One-minute demo script

**00:00–00:08** — Open Nightline. “This is a weekly student support pulse. The first screen separates what stays on the device from what can become public.”

**00:08–00:18** — Change the three answers and type a short private reflection. “Exact values and this note are stored locally. The public preview shows only the coarse band.”

**00:18–00:28** — Select Preview and connect 1AM. “The app discovers UUID-keyed Midnight wallet providers, prefers 1AM, and resets the session whenever the network changes.”

**00:28–00:40** — Choose **Deploy my worker** and approve in 1AM. “Every student deploys their own Compact worker from the browser. Nightline waits for finality, then retains the real contract address and deployment transaction hash.”

**00:40–00:53** — Choose **Prove & send signal** and approve. “The circuit checks three private answers, worker control, and a one-use nullifier. Only the support band crosses the privacy boundary.”

**00:53–01:00** — Show the receipt and metrics. “This is a finalized on-chain transaction. The backend stores the public receipt for aggregate planning, while Gemini can explain the public proof policy without receiving any student answers.”
